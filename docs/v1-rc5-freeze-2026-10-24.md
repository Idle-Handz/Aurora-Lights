# v1.0 RC5 source freeze

Candidate: **1.0.0-rc.5**, on `feature_public-v1.0-build-preparation`.
The commit adding this record identifies the frozen source. Its parent is the
published RC4 commit, `6e6ba27b7b6524f0af66a5624d1b2fffa726daf5`.

## Candidate scope

Aurora Lights (or Aurora Lights Suite) remains the umbrella name. The clients
are Aurora Reflections and Aurora Legacy, with source projects and directories
named `Aurora.Reflections` and `Aurora.Legacy`. Namespaces, build workflows,
resource references, documentation and generated notices follow those names.

Existing application IDs, update identity, settings locations, character files,
imported content and account configuration retain their compatibility with
earlier installations. This source freeze does not update installed apps.

Windows x64 and Android ARM64 remain the stable release targets. Windows ARM64
and macOS remain experimental; Web remains deferred.

## Validation and publication boundary

Before freezing, the naming changes passed local Windows x64, Android ARM64 and
Legacy Release builds, 161 focused character/PDF/lifecycle tests, 41 interface
regressions and 16 licensing tests. Asset integrity, generated notices and the
reviewed corresponding-source archive boundary were also verified.

Hosted Tests, Windows, Android and Legacy workflows must validate this exact
frozen commit. Their run IDs, URLs and outcomes are recorded with the commit
and tree identifiers in the local RC5 freeze record. A change to the source
requires a new frozen revision and checks against that revision.

RC4 remains the published prerelease and retains its existing tag and assets.
RC5 needs package acceptance before publication: Windows x64 installer/portable
and updater checks, and Android ARM64 acceptance using the production signing
identity for any in-place phone update. Hosted CI output alone does not replace
that installed-package acceptance.
